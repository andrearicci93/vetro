Vetro vs AeroTizen, free-my-tv and TizenBrew

Updated 10 November 2026 · Checked on 2026-11-10 against the AeroTizen, free-my-tv and TizenBrew READMEs, the TizenBrew guide, and the Vetro 0.5.0 README, CHANGELOG, SECURITY.md and PERFORMANCE.md.

These four projects solve different problems. AeroTizen and free-my-tv give you a nicer home screen without root. TizenBrew is a loader for modded web apps such as TizenTube, not a launcher. Vetro needs root, and in exchange it can replace Samsung's Home, switch off tracking services and remap the remote. If you want a better-looking app row and nothing else, you probably do not need Vetro. This page compares them from each project's own documentation. This site is published by the Vetro project, so weigh that.

What does Vetro offer?#

Vetro runs on the TV with root and serves a dashboard you open from a computer or phone. Per its README, the launcher shows the same apps as Samsung's Home, in the same order, and returns after a restart or standby, with Samsung's Home one press away. In a single run on the Q80A, available RAM went from 533 MB to 662 MB with the launcher on, about 24% more. PERFORMANCE.md says that is a memory figure only: nothing there shows a change in frame rate, input latency or time to open an app.

The rest of Vetro is the debloater (Quick settings and a Task manager that lists every app and service), a Remapper for remote buttons, MQTT for Home Assistant and diagnostics. The README says every switch can be turned back on. The root comes from Chris Ritsen's samsung-tv-root research, and Vetro is experimental and ships no signed installer: you use a package signed for your TV, for example with Apps2Samsung (see Vetro's root requirements and the install guide). The dashboard runs over plain HTTP; since 0.5.0 it uses a pairing code, but pairing is automatic and the dashboard is open until the Vetro app on the TV has been seen (SECURITY.md). Vetro was developed on the Q80A and community reports cover other models; see the tested TVs.

Pick it if you want the debloater and the remapper as well as a launcher, and you accept the risks of rooting. Do not pick it if you only want a different home screen, or if you cannot get root on your TV.

AeroTizen#

AeroTizen puts your favourite apps and HDMI inputs in one place and adds Continue Watching, weather and automatic location. Its README says both Home options work without root and links a separate, optional root setup guide.

You install it with the aerotizen command-line tool, which runs on macOS, Windows x64 and Linux x64: enable Developer Mode, set the host PC IP, then discover, status, certs (Samsung sign-in) and install launcher. There are two ways to reach it from Home. "Native Home" sends Home presses to AeroTizen and tries to open it at power-on, after the CLI backs up the original Home and startup settings. It is marked experimental, and the README says it is reported not to work on Tizen 10, where you should use the watcher. The watcher, the default option, reopens AeroTizen when it sees the TV return to Samsung Home. The README warns that some apps, including YouTube and Prime Video, can leave you on Samsung Home.

The repository is tagged "debloat" and credits a debloat project for identifying which Samsung packages are safe to remove, and it links guides for ads and DNS blocklists, but the README does not clearly say AeroTizen removes packages itself. It says to use it at your own risk and that it is not affiliated with Samsung. Pick it for a home screen with no root.

What is free-my-tv?#

free-my-tv is a fast home screen for Google TV, LG webOS and Samsung Tizen. On Samsung it is an app you open; Samsung's home screen stays in place and nothing is rooted. You turn on Developer Mode, install through TizenBrew Installer (or build it and run a Python script), and optionally enable Autorun Last App so the TV opens into it. The README lists trending picks that need your own TMDB key, a shelf of apps, an inputs drawer, weather, a theme and a screensaver.

Its Samsung compatibility notes say: it needs a Samsung TV from 2015 or newer; 2015 and 2016 TVs cannot run TizenBrew and need a self-built install; TV Settings is missing from the drawer on 2015 and 2016 sets and freezes on 2017 and 2018 ones; and autorun does not reopen the app on 2019 and 2020 TVs. The README has a hide_apps setting that hides built-in apps from its own shelf, and its list of system changes has no Samsung entries. Pick it for a simple shelf of apps; it does not document any tracking switches.

What is TizenBrew?#

TizenBrew runs modded websites such as TizenTube and installs newer apps without going through Tizen Studio each time. Its getting started guide says it needs Tizen 3.0 or later. The preferred route is a desktop installer, with a Samsung account sign-in on Tizen 7 and above; a command-line route exists; the USB demo package is deprecated because Samsung shut down the service needed to make it. It is GPL-3.0 licensed.

It is not a launcher and not a debloater. It is a loader, and the apps it loads are the point: TizenTube is the example in its README. free-my-tv uses it as an install route. Pick it if you want modded YouTube or similar and nothing more.

Can I combine them?#

Some pairings are documented. free-my-tv installs through TizenBrew Installer. Vetro's installation guide names Apps2Samsung as the fastest way to install Vetro. We have not tested Vetro's launcher together with AeroTizen's Native Home, and both want the Home key, so do not assume they coexist.

Which tool should I choose?#

  • For a nicer home screen without root, use AeroTizen or free-my-tv.
  • For YouTube with the ad blocking TizenTube describes, and no root, use TizenBrew with TizenTube, or the Apps2Samsung route in the TizenTube guide.
  • For lower memory use, tracking services switched off and remapped remote buttons, use Vetro on a rooted TV, accepting a beta launcher and an HTTP dashboard. Read whether rooting is safe first.
  • For fewer ads on the home screen only, read remove ads from the Samsung TV home screen first. A launcher may be more than you need.

For how the native launcher differs from web ones, see why Vetro's launcher is native and a custom launcher for a Samsung TV. What each Vetro switch does is in the switch reference.

Limits#

This comparison comes from each project's documentation, not its code, and we did not run AeroTizen, free-my-tv or TizenBrew for this page. Supported TVs and maintenance status in those repositories change, so check them before you decide. Other projects exist in this space and are not covered.
