Root a Tizen 6 Samsung TV (2021): models and firmware

Updated 10 November 2026 · Checked on 2026-11-10 against the Vetro 0.5.0 README compatibility table, the CHANGELOG compatibility entries and the install guide.

Samsung's 2021 TVs run Tizen 6.0, and this is the generation Vetro is built on: the project's reference TV is a Q80A. Five 2021 models are in the compatibility table. Four are reported working; the fifth, the AU7000, got the dashboard but its root agent did not connect. Vetro is experimental, needs root and ships no signed installer (see the risks).

The root comes from Chris Ritsen's research. That repository is written for researchers and can contain exploit code. This page contains none; for the general picture see how to root a Samsung TV.

Which 2021 Samsung TVs have been reported?#

TV Firmware Status Report
Q80A (QE50Q80AATXZT) T-NKM2DEUC-2301.1 Developed and tested the project's own TV
Q70A (QE55Q70AATXXC) T-NKM2DEUC-2301.1 Reported working #8
Q60A (QN70Q60AAVXZC) T-NKLAAKUC-2310.0 Reported working; listen port changed to avoid a clash #28
QN85A (GQ65QN85AATXZG) T-NKM2DEUC-2301.1 Reported working; back after a reboot once the owner enabled the service's on-boot and auto-restart flags no issue number
AU7000 (UA50AU7000UXTW) T-KSU2EUABC-2310.0 Service and dashboard work; the root agent did not connect, so root features stay off #134

What did each report actually confirm?#

The Q70A report (firmware 2301.1) says setup with root access completed, that Quick settings, the Debloater and domain blocking were used, and that the diagnostic export confirmed 29 controls against the TV's own method list, according to the changelog. It is the most complete 2021 report apart from the reference TV.

The QN85A report has no public issue, so the only evidence is the changelog entry: the app, the service and the UID-0 agent were working and recovered after a reboot, once the owner had enabled the service's on-boot and auto-restart flags. A new owner should not assume that recovery is automatic. The changelog also records that a DNS filter blocking one Samsung certificate host made Certificate Manager fail on that TV.

A contributor's test on a Q60A used a personal certificate; the changelog says the service started on every launch of the app there. "Reported working" always means the owner said what worked, not that every feature was tried.

Why did the Q60A need a different port?#

The Q60A owner changed the listen port to avoid a clash with tizen-youtube, which uses the same default port. The changelog says the same about TizenTube. If another app already holds the port, Vetro says so in its service log and retries instead of taking over. The TizenTube article covers the interaction.

What went wrong on the AU7000?#

The AU7000 report (#134) is the one failed 2021 result in the README. The service and dashboard ran, but the root agent did not connect because the Host PC IP step was not confirmed, so everything that needs root stayed off. The README's 2021 row says one TV needs that step confirmed. The install guide has the step as its own part and a troubleshooting table that starts from what the status page shows, so read it before concluding a TV cannot be rooted.

If your TV is not listed, open a diagnostic report issue with the exact model, firmware and what worked or failed. The README says the report excludes credentials, IP and MAC addresses, serial numbers and viewing history; read it before you upload it.

What should I check before I try a 2021 TV?#

  • Your exact model code and firmware string, using the model code decoder.
  • That the TV is on Tizen 6. Samsung TV Tizen version by year lists the versions.
  • That Developer Mode works and that you can enter an IP address. The Developer Mode guide lists the usual snags.
  • That you allow time: after a cold boot, startup and root can take up to 90 seconds, according to the install guide. Does root survive a restart says what has been measured.

Next steps#

If your TV is a 2021 set that behaves like the AU7000, read the install guide troubleshooting table before assuming the Host PC IP step was enough. For the next generation, see the 2022 TVs on Tizen 6.5; for the older ones, the 2019 and 2020 page.
