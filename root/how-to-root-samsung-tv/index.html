How to root a Samsung TV (Tizen): what works in 2026

Updated 10 November 2026 · Checked on 2026-11-10 against the Vetro 0.5.0 README compatibility table, CHANGELOG and install guide, the samsung-tv-root repository, Samsung's TV device and model groups pages and the Bishop Fox advisory.

Rooting a Samsung TV means getting a process with user ID 0 on it, which bypasses the sandbox normal apps live in. On a Samsung Tizen TV that is possible on some models and firmware versions, through public security research, and it is not a supported feature. No single method works on every set, and a firmware update can change the result.

The root used by Vetro builds on Chris Ritsen and contributors' samsung-tv-root research; the details are in that repository, not here. The linked research repositories are written for researchers and can contain exploit code. This page contains none and is not a guide to running any of it.

What does root mean on a Samsung TV?#

Tizen is a Linux-based system. Apps on the TV run in a sandbox with limited rights. Root, in practice a process with user ID 0, can do what that sandbox forbids: stop or disable system services, change which app starts on the Home key, read process and memory information, and edit system settings.

That is why privacy and speed tools need it. Switching off a component that sends viewing data, or closing Samsung's Home to free memory, is not possible from a normal app.

What does root not give you?#

Root on a TV is broad access, not a permanent unlock. The upstream project says that the agent still has Samsung's User SMACK label and that UID 0 is not proof that every security boundary is gone. It also describes root and its changes as volatile, so the root agent has to come back after each start.

The same access can break the TV if used carelessly. Our risk guide lists what has actually gone wrong. Two cases are documented in the Vetro changelog, and both involve booting:

  • On the Q80A, disabling Samsung's Home app can keep the TV from finishing its boot. Vetro's custom launcher leaves Home enabled and closes it after each Home press; the separate Samsung Home switch at the bottom of the Custom launcher tab asks for confirmation.
  • Opening Samsung's AgingApp could leave a TV starting a factory colour test at every boot, even after a factory reset (#135). Vetro 0.5.0 no longer opens that app, and Quick settings offers Turn off the factory test. The changelog says this guard was tried only against a simulated TV.

Which Samsung TVs have been rooted?#

Vetro is developed on a Samsung Q80A (2021, Tizen 6). Every other TV in the project's compatibility table is there because an owner reported it, usually with a diagnostic export. "Reported working" means the owner said what worked; it is not a test of every feature. The tested TVs list has the firmware string and issue behind each report.

Model year Tizen at launch Reports
2024 8.0 Q65D, S90D (reported on Tizen 9); root problems on some Tizen 9 and 10 sets (#91, #99)
2023 7.0 S90C, S95C, CU7179 (reported on Tizen 9.0)
2022 6.5 Q67B, BU8002, QN85B, S95B, The Frame LS03B
2021 6.0 Q80A, Q70A, Q60A, QN85A; the AU7000 got the dashboard but its root agent did not connect (#134)
2020 5.5 TU7090 (#132) and T4300 (#128): dashboard, app list and diagnostics work; root features unavailable
2019 5.0 Q80R works only with a personal port, not the stock package
2018 4.0 NU7090: dashboard, app list and diagnostics work; root features unavailable

The README says the root features work on Tizen 6 or newer, and that older TVs get the dashboard, app list and diagnostics only. It lists the confirmed reports and says there is no confirmed range outside them. It also says the QN90B and QN90F, where the upstream root route has been demonstrated, were not tried with Vetro. If your TV is not listed, open a diagnostic report issue with the exact model, firmware and what worked or failed. The README says the report excludes credentials, IP and MAC addresses, serial numbers and viewing history; read it before you upload it. Read Samsung TV Tizen version by year to find out which version your TV has, because a 2023 or 2024 set can run a newer Tizen than it launched with.

Where do I find the report for my model year?#

Each model year has its own page with the firmware strings and the caveats from the changelog:

  • 2021 TVs, Tizen 6: the reference generation, with the AU7000 that did not connect.
  • 2022 TVs, Tizen 6.5: the Home cache fix and what the Q67B and S95B reports left unconfirmed.
  • 2023 TVs, Tizen 7 and later: the installer flags caveat and a 2023 TV on Tizen 9.
  • 2024 TVs, Tizen 8 and 9: owner reports next to the failed Tizen 9 and 10 reports and outside research.
  • 2019 and 2020 TVs, Tizen 5: the Q80R port, the two 2020 dashboard-only reports and why older Tizen differs.

What do you need before you start?#

Developer Mode on the TV comes first. Samsung documents it on its TV device page, and our Developer Mode guide covers the usual problems.

You also need a signed package. Vetro is experimental, needs root and ships no signed installer: you build the package and sign it with your own Samsung certificate, or use a community tool such as Apps2Samsung. The install guide has the steps, and the risk guide says what you accept.

Know your exact model and firmware, and compare them with the table above. How to read a model code and firmware string explains what each part means. Then allow some time: after a cold boot, startup and root can take up to 90 seconds, according to the install guide.

Does root survive a restart or an update?#

Root is volatile, so the root agent has to come back after each start. The project's release audit records one cold boot on the Q80A where root came back, and the README gives an S90D owner's account of the agent returning after a full restart. Neither is a guarantee for other models. The changelog says cold-boot persistence was not confirmed in the 2022 Q67B report and not reported for the 2024 Q65D. See does root survive a restart.

Firmware updates can change the result even within a model family. Read will a firmware update remove root and how to stop automatic updates.

What about newer TVs and other public research?#

Security researchers have published work on Tizen well beyond Vetro's compatibility table. Bishop Fox's advisory describes an arbitrary command injection in the Samsung Debug Bridge (SDB) service. It needs Developer Mode and an attacker on the host IP address set in that mode. Bishop Fox demonstrated it on Tizen 5.5, 7.0, 8.0 and 9.0, and believes every Tizen version with SDB is likely affected.

Other repositories describe routes for specific 2024 models, one of which says it needs no Developer Mode. That is other people's research, not a Vetro feature, and we do not describe or test those routes here. A diagnostic report from someone with the same model and firmware is the best evidence you can get without trying it yourself.

What can go wrong?#

  • A privileged change can break a TV feature or keep a Q80A from finishing its boot, as described above.
  • Vetro's dashboard runs over plain HTTP, so it belongs on a trusted network. Pairing is automatic once the TV app has been seen; see the security model.
  • You can undo most changes, but not all. Uninstalling Vetro lists what stays behind.

Does rooting void the warranty?#

We cannot say. Read Samsung's terms for your TV and region before you start. Nothing on this page is warranty advice.

Do the "root any Samsung TV with a USB stick" guides work?#

We found no source that documents a USB-stick root for a Tizen TV. Samsung's TV device page says that for security reasons, installing applications or widgets through USB is no longer supported. The routes that do work need Developer Mode or a browser exploit, not a USB stick.

Samsung's model groups page starts its Tizen list with a 2015 group, and guides that promise a USB stick and a rooting app are usually about Android TV boxes or older SamyGO-era Samsung sets, not Tizen. Treat them as unreliable.

Frequently asked questions

Can you root a Samsung TV?

Some Tizen TVs, yes. Vetro owners' reports show root features working on TVs from 2021 to 2024, a 2019 Q80R works only with a local port, and 2018 and 2020 TVs get the dashboard only. It depends on the exact model and firmware, and there is no official or universal method.

Is there a one-click root for Samsung TVs?

No. The research behind Vetro needs Developer Mode and a package signed with your own certificate. We found no source that documents a USB-stick root for a Tizen TV, and Samsung says installing apps or widgets through USB is no longer supported.

Does rooting void the Samsung warranty?

We cannot say. Read Samsung's terms for your TV and region before you start. Nothing on this page is warranty advice.

What does root give you on a Samsung TV?

A process with user ID 0, which can do what the normal app sandbox blocks: stopping or disabling system services, changing launcher behavior and reading system state. It does not remove every Samsung security boundary.
