Install Vetro on a Samsung TV with Apps2Samsung

Updated 10 November 2026 · Checked on 2026-11-10 against Vetro 0.5.0's published INSTALLATION.md, README, CHANGELOG, SIGN-IN.md and UPDATING.md, and the Apps2Samsung README.

To install Vetro with Apps2Samsung: turn on Developer Mode on the TV, run Apps2Samsung on a computer or phone on the same network, pick Vetro from its catalog and confirm the root badge, open Vetro once on the TV, then set Host PC IP to 127.0.0.1, restart the TV and open the dashboard at http://TV_IP:8099/. There is no signed installer to download, because a Samsung certificate belongs to its owner. Vetro is experimental, needs root and its launcher is in beta, so read is it safe to root a Samsung TV first.

What is Apps2Samsung?#

Apps2Samsung is an MIT-licensed installer for Samsung Tizen TVs. Its README says it runs on Windows, Linux, macOS, Android and iPhone, ships a command line tool (apps2samsung-cli) and has a community catalog of 130+ apps. The first install signs you in to Samsung once to make a signing certificate, which is then reused. It reports what is still wrong when a TV is not ready, such as Developer Mode off, a Host PC IP pointing elsewhere or a restart needed.

The Vetro README lists it as the recommended way to install, and two community reports used it: #10 on a 2024 Q65D and #17 on a 2023 CU7179, both listed as reported working. Apps2Samsung is a separate project and not affiliated with Vetro or Samsung.

What do I need before I start?#

  • A TV you own or are allowed to administer, listed in the README compatibility table or the tested TVs. Vetro is developed on a Q80A; other models are reports, not guarantees.
  • A computer or phone on the same trusted network. The dashboard uses plain HTTP; see the security notes.
  • The package with the root integration. The app-only package shows the TV's apps but cannot change anything and reports "TV platform adapter unavailable".

You never run C# files or DLLs yourself; they are parts of the root integration and start by themselves. The root comes from Chris Ritsen's samsung-tv-root research.

How do I install Vetro with Apps2Samsung?#

  1. Get Apps2Samsung from its releases page: desktop app, Android app or command line.
  2. Turn on Developer Mode on the TV: open Apps, enter 12345, switch it on, enter the address of the computer or phone running Apps2Samsung in Host PC IP and restart. Fixes are in how to enable Developer Mode.
  3. Find Vetro in the catalog under Tools. It has a root badge; confirm when Apps2Samsung asks. From the command line: apps2samsung-cli install "Vetro" --tv TV_IP --allow-root.
  4. Sign in to Samsung when asked, on the first install only, to create the certificate for your TV. Certificate problems are covered in certificate errors when installing.
  5. Change the port only if needed. Vetro uses 8099, and the guide says to change it only if another app on the TV uses the same port, for example tizen-youtube. A Q60A report (#28) did. The port is written into the package, so changing it later means installing again.

If you installed 0.5.0 before 7 November 2026, the CHANGELOG says to reinstall with Apps2Samsung: in-place update does not offer the republished build, because the version number is the same.

What are the last steps after the install?#

The guide ends every route with the same two steps.

  1. Open Vetro on the TV once. The guide calls this required: on some TVs the installer registers the service with start at boot and auto-restart off, and Vetro turns them on by itself only after it has run once and the root agent has connected (#25). A visible icon or an accepted install is not proof that the background service works.
  2. Open http://TV_IP:8099/ from a browser on the same network. Pairing is automatic: once the Vetro app on the TV has been seen, a browser pairs with a six-digit code shown on the TV (sign-in guide).
  3. Open the Developer Mode screen again (Apps, then 12345), set Host PC IP to 127.0.0.1 and restart the TV.
  4. Wait up to 90 seconds, then open the dashboard. It says Root agent: connected when it worked.

Root helper startup goes through the TV's own SDB service, which is why the TV has to talk to itself. The guide says this step is tested on a Q80A and that reports from other models describe it as the step that made the TV root itself. While it is set, a computer cannot use SDB on that TV by default. To install a new build from a computer, put the computer's IP back, restart, install, and repeat the step. Do not change the TV's custom DNS for this. More in connecting with sdb.

If the dashboard does not say connected, open http://TV_IP:8099/status (if pairing is on, pair the browser first):

You see Meaning
"mode": "app-only" The package has no root integration
"mode": "tv-integration" and agent not connected Check Developer Mode, Host PC IP 127.0.0.1, a restart and 90 seconds
The page does not load The background service is not running; open Vetro once and reload

How do I check that it starts by itself?#

The guide's test is to fully power off the TV, unplug it for 30 seconds, turn it on and check /status and /monitor?scope=summary without opening Vetro. You are looking for a new boot, a running service and an authenticated UID-0 agent. Standby is not a cold boot. Details are in does root survive a restart.

Can I update Vetro without reinstalling?#

Yes, in most cases. Quick settings, General, Software update checks GitHub when you press the button, verifies a signed bundle and replaces the files, with no computer attached and Host PC IP staying at 127.0.0.1. It cannot change what config.xml declares; when a version does, you install again with Apps2Samsung.

What if I would rather sign it myself?#

The installation guide has two other routes. A coding agent with a terminal can follow the guide for you; the guide names Codex or Gemini CLI, says not Claude because its cybersecurity safeguards stop it on the root steps, and says to type passwords yourself and never paste them into the chat. The manual route needs Tizen Studio's TV extension and Samsung Certificate Extension, your own certificate profile bound to your TV, and the root builder in the rooting folder with your certificate paths and passwords in environment variables. Install with tizen install, not sdb install, which a community report found did nothing without an error. The steps are in INSTALLATION.md.

Limits#

Compatibility is by model and firmware, not by year, and a firmware update can change it. To remove Vetro, see uninstall Vetro and clean up. The main walkthrough is how to root a Samsung TV. Vetro is not affiliated with Samsung.
