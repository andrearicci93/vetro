Samsung Q80A with Vetro

Developed and tested · Model code QE50Q80AATXZT

The Q80A is the TV Vetro is developed on. Every feature is tried here first, including the Launcher, the root agent after a cold boot and the self-update path. A second firmware, 2310.0, has also been used for test runs.

Before you try it on this TV

A firmware update can change the result, even within one model family, so compare your firmware string with the one above. Vetro needs root, which comes from a package you build and sign yourself; the install guide covers the route, and Developer Mode comes first. The closest rooting guide for this model year is Root a Tizen 6 Samsung TV (2021): models and firmware. Read the risks too. Vetro is experimental and not affiliated with Samsung.
