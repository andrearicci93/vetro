Where the project's README does not state a Tizen version, the table shows the version Samsung launched that model year with, marked "by model year". Samsung's update policy can move a TV to a newer Tizen, as the GU75CU7179 shows. Read Samsung TV Tizen version by year and how to read a model code and firmware string before you compare your TV with this list.

Not on the list?

Open a diagnostic report issue with your exact model, firmware and what worked or failed. Failed attempts help too. The report excludes credentials, IP and MAC addresses, serial numbers and viewing history; read it before you upload it. Start with how rooting a Samsung TV works and the risks.
