Samsung QN900F with Vetro

Root connected after retries in a test build · Model code QA65QN900FWXXY

Root connected after retries in a test build, with the launcher off during the test, according to the README. Earlier builds failed on this model (#193, #194).

Root on Tizen 10 starts in Vetro 0.7.1. This report is from a test build; reports for the final 0.7.1 build are still pending and feature coverage varies by model.

Before you try it on this TV

A firmware update can change the result, even within one model family, so compare your firmware string with the one above. Vetro's launcher, privacy switches and remapper require compatible root support. Apps2Samsung handles signing and installation; manual signing is another route. The install guide covers the route, and Developer Mode comes first. Read the Tizen 10 compatibility notes. Read the risks too, and what a firmware update does to root. Vetro is experimental and not affiliated with Samsung.
