Samsung QN80F with Vetro

Root unconfirmed with 0.7.1 · Model code QN80F

Root stopped connecting with Vetro 0.5.0 after a firmware update (#181). The README says root is still unconfirmed on this model with 0.7.1, which adds a root route for Tizen 10.

What this means for your TV

Vetro's README says root on Tizen 10 starts in Vetro 0.7.1 and records it on four other 2025 models in test builds (S85F, Q70F, U8000F, QN900F). On this model it is still unconfirmed with 0.7.1, so the launcher, privacy switches and remapper may not run. On some Tizen 10 models the dashboard, app list and diagnostics were reported working; see the model report for what was checked. If your TV roots, read what a firmware update does to root before the next update. Vetro's guide to blocking updates without root says that, without root, cutting the TV's internet access at the network is the reliable way to prevent automatic updates. Vetro is experimental and not affiliated with Samsung.

Other 2025 TVs

  • Samsung S85F: root connected in a test build
  • Samsung Q70F: root connected in a test build
  • Samsung U8000F: root connected in a test build
  • Samsung QN900F: root connected after retries in a test build
