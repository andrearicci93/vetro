What Vetro does

Launcher

A native, glass-style bar on the Home key with the same apps in the same order. On the Q80A, available RAM went from 533 MB to 662 MB while it ran (one measurement, memory only). In beta. More

Debloater

Switches for advertising, viewing data, HbbTV, voice assistants and automatic firmware updates, plus a task manager that lists every app and service. What each switch changes

Remapper

Press a remote key, pick an app, save. Shortcuts survive restarts, and a key can send an MQTT message to Home Assistant. How it works

Vetro's main features need root on a compatible TV. Install with Apps2Samsung or follow the manual signing guide. It is experimental software, independent from Samsung. Read the risks before you start.
