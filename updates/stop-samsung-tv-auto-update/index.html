Firmware updates

Stop Samsung TV automatic firmware updates: options

Updated 21 November 2026 · Checked on 2026-11-21 against Samsung US's Auto Update support page, the samsung-tv-root README, Vetro issue #223, and the Vetro 0.7.0 CHANGELOG, UPDATES-WITHOUT-ROOT.md, DOMAIN-FILTER.md and dashboard labels.

To stop Samsung TV automatic firmware updates, open Settings, go to Support, then Software Update, and if Auto Update is on, select it once to turn it off. That covers firmware installs only: Samsung says app and Smart Hub updates continue. On a rooted TV the toggle is not enough to protect root: a forced update has already removed root from a TV with it off (#223). This page gives Samsung's menu path, the router option and what Vetro 0.7.0's update lock does.

How do I turn off Auto Update in the menu?#

Samsung's US support page gives these steps. Menu names and layout differ between models and years.

  1. Open Settings, choose All Settings, then Support.
  2. Select Software Update.
  3. Look at Auto Update. If it is on, select it once to turn it off. If it is already off, leave it.

Samsung says that agreeing to the Smart Hub terms during first setup turns Auto Updates on automatically, and that after an update your video and audio settings might be reset to defaults. You can still check by hand with Update Now.

If Software Update is greyed out, Samsung says a streaming app is running in the background; switch to the TV input or press the Samsung TV Plus button on the remote.

Why does the TV still update some things?#

Samsung's page states that "other app updates or Smart Hub updates will download and install automatically." The Auto Update toggle is about the TV software; app and Smart Hub updates are separate.

Vetro's guide to blocking updates without root goes further. It says Auto update only decides what the TV does with a firmware image it has already found, and lists four update paths that run on their own: over-the-air firmware, app and package updates, app-binary downloads and system components. With the toggle off, the background firmware loop still starts and the other three never look at the setting.

Can I block updates on my router?#

Yes. Vetro's without-root guide says that without root the network is the only reliable block, and recommends denying the TV internet access on the router for both IPv4 and IPv6, or putting it on a network that reaches your home devices but not the internet. If you need streaming apps, allow only the hosts they use. It also says a DNS blocklist alone is not enough, because the TV can reach a host by its address, use another resolver or go over IPv6. A firmware file on a USB stick still installs without any network. The owner in #223 reports that DNS, IPv6 and router blocks were in place when the forced update installed, so treat any network block as a precaution, not a guarantee.

Blocking only update hostnames is a smaller step with side effects. Vetro's domain filter notes identify sas.samsungcloudsolution.com and sas.samsungcloudsolution.net as the software-update servers, from strings in the Q80A firmware, and say that blocking them stops firmware updates. They also say Vetro does not refuse these names, because it is a decision for the owner, and that a Quick settings switch is easier to undo.

Those two names come from Q80A firmware (model page). They are not a tested blocklist for other Samsung TVs, and a router or DNS rule only affects the devices it covers. Filters can also break features, so read blocking Samsung TV telemetry with DNS before you edit lists.

The root research behind Vetro mentions that its author's TVs are blocked from the internet after Developer Mode is enabled (samsung-tv-root README). That is the author's setup, not advice.

What does Vetro's switch do?#

Vetro 0.7.0 has a Block firmware and software updates switch in Quick settings, General, Essential settings. It replaces the 0.5.0 switch, which only set the menu's Auto update value. It is off until you turn it on and needs root; without root the dashboard shows Root required and points to the network block above. The dashboard's description warns that Samsung is trying to block root with remote firmware updates.

According to the CHANGELOG, the switch stops and masks every update service, not just the menu setting: the background firmware loop, the app and package updater, the app-binary manager, the system component updater and the preview updater. It turns the auto-update and app-binary switches off, removes the download markers and applies the lock again after every restart. On TVs that run the AT-HUB boot step (Tizen 6, 6.5 and 9) the lock is applied at power-on, before the update services start; on other firmware it starts with Vetro's root agent. USB recovery is left working, and turning the switch off restores the previous Auto update value.

Two limits come with it. The behavior was read from the Tizen 6, 6.5 and 9 firmware and tried on a Q80A (model page) after a cold reboot; other models are not tried. And while it is on, Samsung's firmware and app updates do not install, so security fixes wait until you turn it off. It can help keep root; it does not guarantee it, and a firmware update that lands anyway replaces everything it does.

Vetro is experimental, needs root and ships no signed installer. Read whether rooting a Samsung TV is safe and how to install Vetro with Apps2Samsung before relying on it, and see Vetro's root requirements for the route. If your TV still roots, turn the switch on before the next update rather than after.

Which option is for whom?#

Option Needs root What it covers Caveat
Menu toggle (Support, Software Update, Auto Update) No What the TV does with a firmware image it found App and Smart Hub updates continue; other update paths never read it
No internet for the TV on the router (IPv4 and IPv6) No Every update that needs the network Streaming apps need their hosts allowed; USB updates still install
DNS or hostname block No Names the TV looks up through your resolver Not enough alone; hosts taken from Q80A firmware, not a tested list
Vetro's Block firmware and software updates Yes Every update service on the TV, applied again at each boot Tried on a Q80A only; Samsung's app updates stop too

Most people should stop at the first row. A rooted TV with a result you want to keep is the case for the others: Vetro's switch while root works, and the router rule if you want a block that lives outside the TV.

Is turning it off a good idea?#

Turning Auto Update off lets you review updates before installing them, but delaying them also delays security fixes, and Vetro's switch delays app updates as well. If you rely on root, read will a firmware update remove root to see what Vetro's records show, and can you downgrade firmware, because going back is usually not possible.

Limits#

Samsung's US page is the source for the menu path, and your TV's wording may differ, especially outside the US or on older models. We haven't tested whether a firmware prompt can still appear with the toggle off, or whether Vetro's switch holds back a forced update like the one in #223 on TVs other than the Q80A. Nothing here is warranty or legal advice.

Frequently asked questions

How do I turn off automatic updates on a Samsung TV?

On Samsung's US support page the path is Settings, All Settings, Support, Software Update, then Auto Update. If it is on, select it once to turn it off. Menu names vary by model and year.

Does turning off Auto Update stop all Samsung TV updates?

No. Samsung's page says other app updates or Smart Hub updates will still download and install automatically. Vetro's notes add that the toggle only decides what the TV does with a firmware image it has found, while other update paths never read it.

Can I block Samsung TV updates on my router?

Vetro's domain notes identify sas.samsungcloudsolution.com and sas.samsungcloudsolution.net as the software-update servers, taken from Q80A firmware, and say blocking them stops firmware updates. Those notes do not claim a tested blocklist for other models, and blocking can have side effects.

Does turning off auto update keep root on a Samsung TV?

Not reliably. In Vetro issue #223 a forced update removed root from a 2022 TV whose owner had automatic updates off. On a rooted TV, Vetro 0.7.0's Block firmware and software updates switch stops every update path; it can help keep root, but it does not guarantee it.
