# Optional YouTube icon

`youtube.png` is the unmodified `yt_icon_red_digital.png` from the official
[YouTube icon page](https://brand.youtube/youtube-icon), downloaded on
7 November 2026:

- Pack: <https://www.gstatic.com/marketing-cms/78/29/3e68a1414bb28d0b7e47b44c3c91/youtube-icon.zip>
- Member: `YouTube_Icon/Digital/01 Red/yt_icon_red_digital.png`
- Purpose: identify the YouTube content application represented by TizenTube
  when Samsung's YouTube tile/icon is unavailable.

YouTube's name and icon remain their owner's trademarks and are subject to
the linked brand guidelines. This asset is not relicensed as MIT software.
It is copied into the package only with `--with-launcher-preferences`.
